# Blueprint A

A harness-neutral blueprint for an AI-agent development flow with deterministic gates: docs, the gates
as code, and adapters per language (JS/TS, .NET) and per platform (GitHub, Azure DevOps, Kubernetes,
SonarQube). Exported one way from a reference repository; see MIRROR.md in each release.

The first release (v0.5.0) arrives through its pull request.
